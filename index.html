🚀 ArkIDE Flatpak Repository

Install ArkIDE directly from our official Flatpak repository.

🔒 Secure: This repository is GPG-signed for your security!
✨ Multi-Architecture Support: Available for x86_64 and ARM64 (aarch64) systems!

Quick Install (Recommended)

Step 1: Import the GPG key and add repository (one-time setup)

wget -O - https://the-arkide-project.github.io/ArkIDE-Desktop/arkide-gpg-key.asc | flatpak remote-add --user --gpg-import=- arkide https://the-arkide-project.github.io/ArkIDE-Desktop/repo

Step 2: Install ArkIDE

flatpak install --user arkide com.arkide.desktop

Flatpak will automatically install the correct version for your architecture (x86_64 or ARM64).

Alternative: Use .flatpakrepo file

flatpak install --user https://the-arkide-project.github.io/ArkIDE-Desktop/arkide.flatpakrepo

Run ArkIDE

flatpak run com.arkide.desktop

Update

Get the latest version:

flatpak update com.arkide.desktop

Uninstall

flatpak uninstall com.arkide.desktop
flatpak remote-delete arkide

Supported Architectures

  • x86_64 - Standard Intel/AMD processors
  • ARM64 (aarch64) - ARM-based systems (Raspberry Pi 4/5, Apple Silicon via Asahi Linux, etc.)

Verify GPG Signature

You can verify the repository is authentic:

wget https://the-arkide-project.github.io/ArkIDE-Desktop/arkide-gpg-key.asc
gpg --import arkide-gpg-key.asc
flatpak remote-ls arkide --show-details

Manual Installation Steps

Step 1: Download and import the GPG key

wget https://the-arkide-project.github.io/ArkIDE-Desktop/arkide-gpg-key.asc
gpg --import arkide-gpg-key.asc

Step 2: Add the repository

flatpak remote-add --user --gpg-import=arkide-gpg-key.asc arkide https://the-arkide-project.github.io/ArkIDE-Desktop/repo

Step 3: Install ArkIDE

flatpak install --user arkide com.arkide.desktop
